# Nexus Marketing IA

Marketing Operating System da Nexus Digital, desenvolvido em Next.js.

## Funcionalidades

- Dashboard executivo por workspace
- Planejamento por orçamento, demanda e nível de investimento
- Matriz Google x Meta
- Divisão da parcela Google entre GBP e Google Ads
- Campanha guiada
- Persona estratégica
- Conteúdo pelo método RETINA
- Estrutura inicial para Meta Ads e Google Ads
- Importação CSV de performance
- Termos de pesquisa
- Experimentos A/B
- Proposta comercial
- Persistência local no navegador

## Desenvolvimento

```bash
npm install
npm test
npm run dev
```

## Build

```bash
npm run build
```

A camada de integração com OpenAI será conectada em uma etapa posterior. O sistema atual funciona sem chave de API.
